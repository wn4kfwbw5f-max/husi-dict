📖 日常操作 · 加词流程
1打开词条后台 → 输入口令 husi-admin-7q2x9k3m 登录
2「＋ 新增词条」→ 填 词 / 词性 / 释义（释义自己写一句俏皮的）
3乱想Time 不用管 → 直接「保存」→ AI 自动生成延展段
4打开主站刷新 → 搜这个词 → 能搜到 = 同步成功 ✅
5如果你想让别人打开 husidict.top 也搜到这词：因为 GitHub Pages 是静态包、不自动拉云端，需要拉云端 → 注入 dict.js → 重新打包 → 上传 GitHub（找靠谱跑 sync 脚本）

1把新文件打包 zip（找靠谱）
2GitHub 仓库 → 「+ ▼」（Code 按钮左边）→「Upload files」→ 只拖文件、不要拖文件夹 → Commit
